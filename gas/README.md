# 結帳串接 Google 試算表（Google Apps Script）

網站結帳送出後，訂單會寫進你的 Google 試算表，並寄信通知你。

```
顧客在網站按「送出訂單」
        │  (訂單 JSON)
        ▼
Google Apps Script 網頁應用程式（gas/Code.gs）
  ├─ 驗證姓名、電話、取餐方式、商品
  ├─ 用「商品」工作表的價格重新計算金額
  ├─ 產生訂單編號 KIN-20261127-001
  ├─ 寫入「訂單」與「訂單明細」工作表
  └─ 寄信：通知店家／顧客確認信
        │  (訂單編號、金額)
        ▼
網站顯示「訂單編號 KIN-…｜金額 NT$…」
```

## 一、建立試算表與貼上程式（約 5 分鐘）

1. 開啟 <https://sheets.new> 建立新的 Google 試算表，命名為「金日煎餃 訂單」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的程式全部刪掉，貼上本資料夾 `Code.gs` 的全部內容，按 **儲存**（磁碟圖示）。
4. （選填）修改最上方 `CONFIG`：
   - `OWNER_EMAIL`：新訂單通知信要寄給誰（留空 = 寄給你自己的 Google 帳號）
   - `STORES`：取餐門市名稱，需與網站一致
5. 上方函式選單選 **setup**，按 **執行**。
   - 第一次會要求授權：選你的帳號 → 「進階」→「前往（不安全）」→「允許」。這是你自己寫的腳本，Google 對未經審查的腳本都會顯示這個警告。
6. 回到試算表，會看到三個工作表：**訂單、訂單明細、商品**，上方也多了 **「金日訂單」** 選單。

## 二、部署成網頁應用程式

1. Apps Script 右上角 **部署 → 新增部署作業**。
2. 齒輪圖示 → 類型選 **網頁應用程式**。
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（顧客不需登入 Google 才能下單）
4. 按 **部署**，複製「網頁應用程式網址」（結尾是 `/exec`）。
5. 在瀏覽器開啟該網址，看到 `{"ok":true,...}` 就代表成功。

## 三、把網址填進網站

打開 `index.html`，找到：

```js
const ORDER_API='';
```

把網址貼進引號中，例如：

```js
const ORDER_API='https://script.google.com/macros/s/AKfycb.../exec';
```

存檔並推上 GitHub。也可以直接把網址傳給 Claude，請它幫你填好並合併。

填好後，結帳按鈕會從「送出模擬訂單」變成「送出訂單」，訂單會真的寫進試算表。網址留空時，網站維持示範模式。

## 日常使用

| 工作 | 怎麼做 |
| --- | --- |
| 看新訂單 | 「訂單」工作表，最新的在最下面；新訂單狀態為橘色「新訂單」 |
| 更新訂單進度 | 點「狀態」欄的下拉選單：新訂單 → 製作中 → 可取餐／已出貨 → 已完成（或已取消），顏色會跟著變 |
| 改價格／下架商品 | 「商品」工作表改「單價」，或取消勾選「上架」。網站上顯示的價格要另外在 `index.html` 的 `products` 一起修改 |
| 看今天營收 | 選單 **金日訂單 → 今日營收摘要** |
| 每晚收到營收報表 | 選單 **金日訂單 → 開啟每日營收報表**（預設每天 21 點寄出） |
| 測試寫入 | Apps Script 編輯器選 `testOrder` → 執行，會新增一筆測試訂單 |

## 修改程式後要重新部署

改了 `Code.gs` 之後，到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**。這樣網址不會變，網站不用改。

## 注意事項

- **價格以試算表為準**：就算有人竄改網頁上的價格，寫入的金額仍以「商品」工作表計算。
- **防機器人**：表單有隱藏欄位，機器人填了就不會寫入。
- **寄信配額**：一般 Gmail 帳號每天約可寄 100 封，Google Workspace 帳號較多。超過時訂單照常寫入，只是不寄信。
- **個資**：試算表裡有顧客姓名、電話與地址，請不要把試算表分享給不需要的人。
- **付款**：目前沒有線上付款，付款與取餐由門市聯繫顧客。
